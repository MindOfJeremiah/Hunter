## Topics Covered (Ch. 1–14)
1. **Ch. 1** — Hardware, software, data storage, hex/IEEE 754
2. **Ch. 2** — Data types, variables, I/O, assignment, calculations
3. **Ch. 3** — Decision structures, if/else, relational/logical operators
4. **Ch. 4** — Repetition: while, do-while, for loops, nested loops
5. **Ch. 5** — Modules: defining/calling, arguments, local/global vars
6. **Ch. 6** — Functions, library functions, writing your own
7. **Ch. 7** — Input validation loops, sentinel loops, running totals, menus
8. **Ch. 8** — Arrays: basics, processing, parallel arrays, 2D arrays
9. **Ch. 9** — Sorting (bubble, selection, insertion) & searching (sequential, binary)
10. **Ch. 10** — File I/O, using loops/arrays with files
11. **Ch. 11** — Menu-driven programs
12. **Ch. 12** — Text/string processing
13. **Ch. 13** — Recursion
14. **Ch. 14** — OOP: classes, inheritance
